# IBS - סוכנות ביטוח ופיננסים

ברוכים הבאים למאגר הקוד של האתר הרשמי של IBS. 
האתר בנוי כאתר סטטי וכולל "בוט תשואה" (מחשבון השקעות חכם) שמתעדכן אוטומטית מנתוני הבורסה.

## מבנה התיקיות והקבצים בפרויקט

הפרויקט מסודר בצורה הבאה כדי לשמור על קוד נקי ומקצועי:

### 📄 עמודי האתר (HTML)
* `index.html` - עמוד הבית הראשי של האתר.
* `invest.html` - עמוד מסלולי ההשקעה ו**בוט התשואה** (המחשבון המרכזי).
* `travel.html` - עמוד ביטוחי נסיעות לחו"ל.

### 🤖 בוט התשואה (אוטומציה)
* `scripts/` - תיקייה המכילה את קוד הרובוט (`update_returns.py`) שמתחבר ל-Yahoo Finance, שואב את נתוני המדדים בבורסה (S&P 500, נאסד"ק, ת"א 125) ומחשב את התשואות.
* `assets/` - תיקייה המכילה את קובץ הנתונים (`market_returns.json`) שבו נשמרים אחוזי התשואה העדכניים לשימוש המחשבון באתר.
* `.github/workflows/` - המוח של הרובוט בשרת (`update_market_data.yml`). הקובץ הזה אחראי להריץ את הבוט באופן אוטומטי לחלוטין בכל 1 לחודש בחצות.
