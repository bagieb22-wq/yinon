# IBS - סוכנות ביטוח ופיננסים

ברוכים הבאים למאגר הקוד של האתר הרשמי של IBS. 
האתר נבנה כפלטפורמה חכמה שמשלבת תצוגה שיווקית מרשימה יחד עם כלים פיננסיים מתקדמים (מחשבוני תשואה, אוטומציות נתונים ומערכות המלצה דינמיות).

## ✨ פיצ'רים מרכזיים ומערכות שנבנו באתר

### 1. מחשבון תשואות חכם (בוט השקעות)
* **אוטומציית נתוני בורסה:** הוקם רובוט (Python) שמתחבר ישירות ל-Yahoo Finance פעם בחודש ומושך נתוני אמת של ה-S&P 500, נאסד"ק 100 ות"א 125, כולל היסטוריה של 1, 3 ו-5 שנים.
* **סריקת קופות גמל:** הבוט תוכנת במיוחד כדי לסרוק את האתר "מיי-גמל-נט" (MyGemel) בכל חודש, לאתר את טבלת **"קופת גמל להשקעה - כללי"**, ולמשוך משם את ממוצע התשואות הענפי באופן אוטומטי (לרמת דיוק של 2 ספרות עשרוניות).
* **מנגנון הגנה:** במידה והבוט לא מצליח לקרוא את גמל-נט (למשל אם הם שינו את עיצוב האתר), תהליך העדכון נעצר ונשלחת התראת שגיאה למייל כדי שהאתר לעולם לא יציג נתונים שגויים או 0%.
* **מחשבון אינטראקטיבי:** מחשבון השקעות חכם בעמוד `invest.html` שמאפשר ללקוח להזין סכום השקעה כולל, לחלק אותו באחוזים בין מסלולים שונים, ולראות גרף רווחים צפוי. המחשבון כולל גם התרעות שגיאה (למשל אם הלקוח מקצה יותר מ-100%).
* **אוטומציה בשרת:** כל זה מתוזמן לרוץ אוטומטית לחלוטין בכל 1 לחודש בחצות באמצעות GitHub Actions (`update_market_data.yml`).

### 2. מערכת המלצות דינמית (Firebase)
* חיבור האתר למסד נתונים חי (Firebase Firestore).
* טופס באתר המאפשר למבקרים להזין המלצה חדשה.
* משיכה והצגה אוטומטית של ההמלצות (מהחדשה לישנה) ישירות בעמוד הבית, ללא צורך בעריכת קוד.

### 3. אינטגרציות וניהול לידים (WhatsApp ויומן)
* **טפסי יצירת קשר חכמים:** הוקמו טפסים ייעודיים (כמו טופס "עדכון מעסיק" ו"ביטוח נסיעות") שאוספים פרטים ספציפיים (ת"ז, תאריך הנפקה, יעד טיסה וכו') ושולחים אותם ישירות ל-WhatsApp של הסוכנות כהודעה מסודרת.
* **זימון פגישות:** שולבו כפתורי "קביעת פגישה" צפים ומרכזיים המקשרים ישירות ליומן העסקי (Google Appointment Schedule) של ינון.
* **לינקים שותפים (Affiliates):** שולבו קישורי רכישת ביטוח נסיעות ישירים לפספורטקארד והראל בעמוד `travel.html`.

### 4. עיצוב, שיווק וחווית משתמש (UI/UX)
* **קופירייטינג שיווקי:** הטקסטים באתר (למשל באזור עדכון המעסיק) שוכתבו במטרה להוריד חסמים בירוקרטיים ולמשוך את הלקוחות להשאיר פרטים ("תנו לנו לעשות לכם את הסדר!").
* **עיצוב רספונסיבי:** כל העמודים עברו התאמה מלאה למובייל, כולל סידור מחדש של אלמנטים בגלישה ממסכים קטנים.
* **תפריט וניווט:** בניית תפריט אחיד, כפתורים צפים, ואנימציות hover לשיפור חווית הגלישה.

## 📂 מבנה התיקיות והקבצים בפרויקט

### 📄 עמודי האתר (HTML)
* `index.html` - עמוד הבית הראשי של האתר, כולל את טופס עדכון המעסיק ואזור ההמלצות.
* `invest.html` - עמוד מסלולי ההשקעה ו**בוט התשואה** (המחשבון המרכזי).
* `travel.html` - עמוד ביטוחי נסיעות לחו"ל.

### 🤖 רובוטים ואוטומציה
* `scripts/` - תיקייה המכילה את קוד הרובוט (`update_returns.py`) שסורק את Yahoo Finance ו-MyGemel.
* `assets/` - תיקייה המכילה את נתוני התשואה (`market_returns.json`), לוגואים ותמונות.
* `.github/workflows/` - מכיל את מנגנון ההפעלה (`update_market_data.yml`) שמפעיל את כל האוטומציה בשרת כל חודש.
